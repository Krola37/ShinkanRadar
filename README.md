# ShinkanRadar

登録した作品（コミック・ライトノベル・文庫）の新刊発売日を自動で調べ、Googleスプレッドシートの更新・Googleカレンダーへの登録・Discordへの通知までを毎日自動で行うツールです。GitHub Actions上で無料枠で動作します（GAS版からの移植版）。

## できること

- スプレッドシートに登録した作品タイトルをもとに、[sumikko.info](https://sumikko.info/)（ジャンルごとにコミック／ライトノベル／文庫の各ドメイン）から最新刊の発売日を検索
- 最新巻数がスプレッドシート上の記録より新しければ、
  - スプレッドシートの巻数・発売日・ステータス・最終更新日時を更新
  - Googleカレンダーに発売日イベントを登録（重複登録防止つき）
  - Discordに新刊検知の通知を送信（Embed形式、行ごとにON/OFF可能）
- 毎日、その日発売予定の書籍をまとめてDiscordにダイジェスト通知（Embed形式）
- スプレッドシートの列（H列）で特定の行だけ即時・優先処理する手動更新にも対応
- 毎月1日の実行時に、H列（手動更新フラグ）がTRUEのまま＝自動検索で解決できていない作品を、検索リンク付きでDiscordにまとめて通知
- 1日あたりのチェック件数に上限を設け、最終更新日時が古い行から優先的に巡回することでAPIクォータ・実行時間を節約
- GitHub Actionsランナー側の一時的な接続不良を検知した場合、新しいランナーで自動リトライ（最大2回）

## スプレッドシートの列構成

| 列 | 内容 |
|---|---|
| A | 作品タイトル |
| B | 最新巻数 |
| C | 発売日 |
| D | ジャンル（`コミック` / `ライトノベル` / `文庫`） |
| E | ステータス（処理結果の表示用。処理対象の判定には使わない） |
| F | 最終更新日時（この日時が古い行から優先的にチェックされる） |
| G | Discord通知フラグ（`TRUE`で新刊検知時に通知） |
| H | 手動確認フラグ（自動検索で解決できていない作品を示す。月次まとめの対象。TRUEの間は自動検索の対象から外れ、F列だけ日付が更新される。B・C列が入力済みでも自動ではFALSEに戻らないため、解決後は手動でFALSEに戻す） |
| J | 登録反映チェック。B・C列を手動で埋めた後に`TRUE`にすると、次回実行時にカレンダー登録・Discord通知を行い、登録後は自動で`FALSE`に戻る |
| I1 | （内部管理用）本日発売ダイジェストの送信済み日付。リトライ実行時の二重送信防止のためスクリプトが自動で読み書きする。手動で編集する必要はない |

## Discord通知の見た目

- **新刊検知の個別通知**：オレンジ色のEmbed。作品名・巻数・発売日・ジャンルをフィールド表示
- **本日発売ダイジェスト**：青色のEmbed。その日発売の全書籍を箇条書きで表示（スプレッドシートのG列フラグに関係なく、Googleカレンダー上で本日が開始日のイベントを全件集計。2カ月連続発売など複数巻が同時検出された場合でも、各巻ごとの発売日で正しく拾える）
- **月次の手動確認まとめ**（毎月1日のみ）：紫色のEmbed。H列がTRUEのままの作品を、ジャンル別の検索ページへのリンク付きで箇条書き表示

## 動作環境・スケジュール

- Python 3.11 / GitHub Actions（`.github/workflows/update_release_dates.yml`）
- 毎日 UTC 21:00（日本時間 6:00）に自動実行。Actionsタブから手動実行も可能
- 必要なライブラリは [requirements.txt](requirements.txt) を参照

## 必要な環境変数（GitHub Secrets / Variables）

| 変数名 | 内容 |
|---|---|
| `GOOGLE_SERVICE_ACCOUNT_JSON` | サービスアカウントのJSONキー（Secret） |
| `SPREADSHEET_ID` | 対象スプレッドシートのID（Secret） |
| `SHEET_NAME` | 対象シート名（Secret。省略時は "シート1"） |
| `CALENDAR_ID` | GoogleカレンダーのカレンダーID（Secret） |
| `DISCORD_WEBHOOK_URL` | Discord Webhook URL（Secret。任意。未設定なら通知はスキップ） |
| `DAILY_LIMIT` | 1日あたりの自動チェック件数上限（Variable。任意。省略時40） |
